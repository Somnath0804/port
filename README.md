# Somnath Banerjee — Portfolio Website

A responsive, no-photo personal portfolio built with plain HTML, CSS and JavaScript. It is ready for GitHub Pages.

## Files
- `index.html` — page content and project cards
- `style.css` — responsive styling
- `script.js` — mobile navigation and current year
- `.nojekyll` — tells GitHub Pages not to run Jekyll processing

## Publish with GitHub Pages
1. Create a new GitHub repository, for example `somnath-portfolio`.
2. Upload all files from this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for the deployment and open the URL shown in the Pages section.

## Personalise before publishing
Search `index.html` for:
- `your.email@example.com`
- `your-github-username`
- `your-linkedin-username`

Replace these with your real details. Add repository links to project cards when your projects are public.

## Accuracy note
The portfolio includes the education details and project areas previously supplied. It intentionally does not invent awards, hackathon placements, certificates, publications, clinical validation, or employment. Add only achievements you can verify. Update any project status or education detail that has changed before publishing.
